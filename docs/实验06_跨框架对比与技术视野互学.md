# 实验06 跨框架对比与技术视野互学

- 本栈：**UniApp（Vue3 + Vite，JavaScript）**
- 对照栈：**HarmonyOS ArkTS（ArkUI 声明式）**、**Flutter（Dart）**
- 同题：**学生列表**——姓名搜索过滤 + 加载中/空结果两态 + 点击进详情并携带学号（与实验03 同题，便于横向对比）

## 一、概念映射（Concept Mapping）

| 概念 | 本栈 UniApp（Vue3） | ArkTS / ArkUI | Flutter（Dart） |
|---|---|---|---|
| 语言 | JS/TS（动态为主，可选 TS） | ArkTS：TS 超集，强制静态类型、禁用 any/动态属性 | Dart：强类型、空安全，JIT 热重载 + AOT |
| UI 描述 | 单文件组件里写类 HTML 标签（view/text） | 结构体里 build() 用 Column/Row/Text 等组件函数 | Widget 树，build() 返回 Widget |
| 组件定义 | `<script setup>` + template | `@Component struct X { build() {} }` | `class X extends StatelessWidget/StatefulWidget` |
| 父传子 | `defineProps` / props | `@Prop`（单向）/`@Link`（双向）/`@ObjectLink` | 构造函数 final 字段 |
| 组件内部状态 | `ref()` / `reactive()` | `@State` | `State` + `setState()` |
| 跨层共享 | `provide/inject`、Pinia | `@Provide/@Consume`、AppStorage、LocalStorage | InheritedWidget、Provider/Riverpod/Bloc |
| 派生数据 | `computed`（带缓存） | 无内建 computed，方法或 @Builder 每次重算 | getter / build 内计算 |
| 列表渲染 | `v-for` + `:key` | `ForEach(arr, itemGen, keyGen)` | `ListView.builder(itemBuilder, ...)` |
| 条件渲染 | `v-if / v-else-if / v-else` | build() 里的 `if / else`（不需要模板指令） | `if` 语句或三元表达式拼 Widget |
| 事件 | `@click="fn(arg)"`、`v-model` | `.onClick(() => {})`、`.onChange(v => {})` | `onTap: () {}`、`onChanged:` |
| 样式与单位 | `<style scoped>` + rpx（750 设计稿自适应） | 链式属性 `.width(100).padding(12)`，单位 vp/fp | TextStyle / BoxDecoration / EdgeInsets 对象 |
| 页面注册 | `pages.json` 的 pages 数组 | `main_pages.json` 的 src 列表 | `MaterialApp(routes:/home:)` |
| 前进 | `uni.navigateTo({url})` | `router.pushUrl({url, params})` | `Navigator.push(context, MaterialPageRoute(...))` |
| 返回 | `uni.navigateBack()` | `router.back()` | `Navigator.pop(context[, result])` |
| 传参 / 取参 | url 带 `?id=` + `onLoad(options)` | `params:{id}` + `router.getParams()` | 构造函数参数；取参即读字段 |
| 返回带回结果 | EventChannel `getOpenerEventChannel()` / `uni.$emit` | `router.back({params})` 由 onPageShow 读取，或 AppStorage | `Navigator.pop(context, result)` 由上一页 await/回调接收 |
| Tab 切换 | `uni.switchTab`（tabBar 页不能 navigateTo） | `Tabs/TabContent` 组件，或用 Navigation 的多实例 | `BottomNavigationBar` + IndexedStack |
| 异步 | Promise / async-await，单线程事件循环 | 同为 Promise/async-await（ArkTS 标准库） | `Future` / async-await；重活放 `Isolate` |
| 并发 | Web Worker（H5）、worker 线程（App） | TaskPool / Worker | Isolate（独立内存，消息传递） |
| 网络 | `uni.request`（回调式，建议再包成 Promise） | `@ohos.net.http` 的 `http.createHttp()` | `package:http` / `dio` |
| 本地 KV | `uni.setStorageSync`（H5=localStorage，小程序=Storage，App=plus.storage） | `@ohos.data.preferences`（需 flush 落盘） | `shared_preferences` 插件（异步 API） |
| 生命周期 | onLoad / onShow / onHide / onUnload / onLaunch | aboutToAppear / aboutToDisappear，页面级 onPageShow | initState / didUpdateWidget / dispose |
| 构建产物 | `uni build` → H5 / 小程序 / App | hvigor → .hap（只能跑鸿蒙） | flutter build → apk / ipa / web / desktop |
| 调试 | HBuilderX + 浏览器 devtools | DevEco Studio 预览器 + hdc 真机 | 热重载（毫秒级），DevTools |
| 包管理 | npm | ohpm | pub.dev |

### 2.2 对照栈 A（HarmonyOS ArkTS）

```ts
// 路径：entry/src/main/ets/pages/StudentList.ets
// DevEco Studio：新建 Empty Ability 工程 → 用本文件替换 pages/StudentList.ets
// 并在 entry/src/main/resources/base/profile/main_pages.json 的 src 里登记 "pages/StudentList"
import { router } from '@kit.ArkUI'

interface Student {
  id: string
  name: string
  major: string
}

const STUDENTS: Student[] = [
  { id: '2023010101', name: '李思远', major: '软件工程' },
  { id: '2023010102', name: '王雨桐', major: '软件工程' },
  { id: '2023020104', name: '李梦琪', major: '数据科学与大数据技术' },
  { id: '2023030107', name: '李欣然', major: '人工智能' }
]

@Entry
@Component
struct StudentList {
  // @State 相当于 Vue 的 ref：改了它就触发界面重绘
  @State students: Student[] = []
  @State keyword: string = ''
  @State loading: boolean = true

  // ArkUI 没有 computed，用普通方法每次 build 时算一遍（列表小，成本可忽略）
  filtered(): Student[] {
    const k: string = this.keyword.trim()
    return k.length > 0 ? this.students.filter((s: Student) => s.name.includes(k)) : this.students
  }

  // 生命周期：aboutToAppear 对应 onMounted / onLoad
  aboutToAppear(): void {
    new Promise<void>((resolve: (value: void) => void) => {
      setTimeout(() => resolve(), 600) // 模拟网络请求
    }).then(() => {
      this.students = STUDENTS
      this.loading = false
    })
  }

  build() {
    Column({ space: 12 }) {
      TextInput({ placeholder: '输入姓名搜索，如：李', text: this.keyword })
        .height(44)
        .borderRadius(12)
        .onChange((value: string) => { this.keyword = value })

      Text('共 ' + this.students.length + ' 名 · 命中 ' + this.filtered().length + ' 名')
        .fontSize(12)
        .fontColor('#6b7280')
        .width('100%')

      if (this.loading) {
        Column({ space: 8 }) {
          LoadingProgress().width(36).height(36)
          Text('数据加载中…').fontSize(13).fontColor('#6b7280')
        }
        .width('100%')
        .padding(40)
      } else if (this.filtered().length === 0) {
        Text('没有匹配的学生，换个关键字试试')
          .fontSize(14)
          .fontColor('#9ca3af')
          .padding(40)
      } else {
        List({ space: 10 }) {
          ForEach(this.filtered(), (stu: Student) => {
            ListItem() {
              Row({ space: 12 }) {
                Text(stu.name.substring(0, 1))
                  .width(40).height(40).borderRadius(20)
                  .textAlign(TextAlign.Center)
                  .backgroundColor('#4e6ef2').fontColor('#ffffff')
                Column({ space: 4 }) {
                  Text(stu.name).fontSize(16).fontWeight(FontWeight.Bold)
                  Text(stu.major + ' · 学号 ' + stu.id).fontSize(12).fontColor('#6b7280')
                }
                .alignItems(HorizontalAlign.Start)
                .layoutWeight(1)
                Text('›').fontSize(18).fontColor('#9ca3af')
              }
              .width('100%')
              .padding(12)
              .backgroundColor('#ffffff')
              .borderRadius(12)
              .onClick(() => {
                // 路由：pushUrl 进栈，参数走 params
                router.pushUrl({ url: 'pages/StudentDetail', params: { id: stu.id } })
              })
            }
          }, (stu: Student) => stu.id) // keyGenerator：相当于 :key
        }
        .width('100%')
        .layoutWeight(1)
      }
    }
    .width('100%')
    .height('100%')
    .padding(16)
    .backgroundColor('#f5f6fa')
  }
}
```

### 2.3 对照栈 B（Flutter / Dart）

```dart

// 运行：flutter create student_demo && 用本文件替换 lib/main.dart && flutter run
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class Student {

  final String name;
  final String major;

const List<Student> kStudents = [
  Student('2023010101', '李思远', '软件工程'),
  Student('2023010102', '王雨桐', '软件工程'),
  Student('2023020104', '李梦琪', '数据科学与大数据技术'),
  Student('2023030107', '李欣然', '人工智能'),
];

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: '学生列表',
      theme: ThemeData(colorSchemeSeed: const Color(0xFF4E6EF2), useMaterial3: true),
      home: const StudentListPage(),

class StudentListPage extends StatefulWidget {
  const StudentListPage({super.key});

  @override
  State<StudentListPage> createState() => _StudentListPageState();
}

class _StudentListPageState extends State<StudentListPage> {
  final TextEditingController _controller = TextEditingController();
  String _keyword = '';
  bool _loading = true;
  List<Student> _students = const [];

  @override
  void initState() {
    super.initState();
    // Future + 延迟模拟网络：先 loading，600ms 后落数据
    Future<void>.delayed(const Duration(milliseconds: 600), () {
      if (!mounted) return;
      setState(() {
        _students = kStudents;
        _loading = false;
      });
    });
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  List<Student> get _filtered {
    final String k = _keyword.trim();
    return k.isEmpty ? _students : _students.where((Student s) => s.name.contains(k)).toList();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('学生列表')),
      body: Padding(
        padding: const EdgeInsets.all(12),
        child: Column(
          children: <Widget>[
            TextField(
              controller: _controller,
              decoration: const InputDecoration(
                prefixIcon: Icon(Icons.search),
                hintText: '输入姓名搜索，如：李',
                border: OutlineInputBorder(),
              ),
              onChanged: (String v) => setState(() => _keyword = v),
            ),
            const SizedBox(height: 8),
            Align(
              alignment: Alignment.centerLeft,
              child: Text(
                '共 ${_students.length} 名 · 命中 ${_filtered.length} 名',
                style: const TextStyle(color: Colors.grey, fontSize: 12),
              ),
            ),
            const SizedBox(height: 8),
            Expanded(child: _buildBody()),
          ],
        ),
      ),
    );
  }

  Widget _buildBody() {
    if (_loading) {
      return const Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: <Widget>[
            CircularProgressIndicator(),
            SizedBox(height: 8),
            Text('数据加载中…', style: TextStyle(color: Colors.grey)),
          ],
        ),
      );
    }
    if (_filtered.isEmpty) {
      return const Center(child: Text('没有匹配的学生，换个关键字试试', style: TextStyle(color: Colors.grey)));
    }
    return ListView.separated(
      itemCount: _filtered.length,
      separatorBuilder: (BuildContext context, int i) => const SizedBox(height: 8),
      itemBuilder: (BuildContext context, int i) {
        final Student s = _filtered[i];
        return ListTile(
          tileColor: Colors.white,
          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
          leading: CircleAvatar(
            backgroundColor: const Color(0xFF4E6EF2),
            child: Text(s.name.substring(0, 1), style: const TextStyle(color: Colors.white)),
          ),
          title: Text(s.name, style: const TextStyle(fontWeight: FontWeight.bold)),
          subtitle: Text('${s.major} · 学号 ${s.id}'),
          trailing: const Icon(Icons.chevron_right),
          // 路由：Navigator.push 入栈，把 id 作为构造参数传给详情页
          onTap: () => Navigator.push(
            context,
            MaterialPageRoute<void>(builder: (BuildContext ctx) => StudentDetailPage(id: s.id)),
          ),
        );
      },
    );
  }
}
```

详情页取参（Flutter）：`StudentDetailPage(id: s.id)` 用构造函数传参，返回用 `Navigator.pop(context)`；若要带回结果，用 `Navigator.pop(context, '结果')`，上一页 `await Navigator.push(...)` 拿到返回值——这和 uni 的 `navigateBack` + EventChannel 是一个意思：**页面栈天然就是调用栈**。

### 2.4 三处最容易踩坑的差异

1. **列表渲染**：`v-for` 靠 `:key` 做 diff；ArkUI 的 `ForEach` 必须显式传第三个 keyGenerator（不传就用索引，删除项会错位）；Flutter 用 `ListView.builder`，key 通过 `Key` 对象给。
2. **状态更新**：Vue 的 `ref` 靠 Proxy 自动追踪，赋值即刷新；ArkUI 靠 `@State` 装饰器标记的变量赋值触发重绘；Flutter 没有响应式系统，必须 `setState(() { ... })` 通知框架。
3. **路由传参**：uni 把参数序列化进 url，中文/对象要先 `encodeURIComponent` 或 `JSON.stringify`；ArkUI 用 `params` 传对象，类型要自己断言；Flutter 直接把对象塞进构造函数，编译期就有类型检查。

## 三、费曼讲解：用大白话讲清本栈 5 个核心概念

**1）声明式 UI = 点菜，不是炒菜。** 命令式是"我把这个菜捞出来、加点盐、端走"（手动 removeChild/appendChild）；声明式是"我要一份宫保鸡丁"，厨房自己决定怎么做。检验：你能不能用一句话说出"界面 = f(状态)"？说不出来就还没懂。

**2）状态是唯一的真相。** 界面上显示的学号、姓名都不该由你手动改，它们只能是数据的投影：`视图 = f(状态)`。`ref` 像一张便利贴，改数字，视图跟着变；想改界面却去改 DOM，就是在"改投影"而不是"改物体"。由此还得出一条纪律：**能算出来的就别再存一份**（用 `computed`），否则两份数据迟早对不上。

**3）组件 = 带记忆的函数。** 输入 props，输出 UI；有状态组件就是"带抽屉的函数"。状态放哪里？放在所有用到它的组件最近的公共祖先（状态提升），否则就得靠 Pinia 这种"公共储物柜"。

**4）路由 = 一摞盘子。** `navigateTo` 是往最上面放一个盘子，`navigateBack` 是拿走最上面那个，被拿走的页面就销毁了。`switchTab` 是换抽屉：抽屉里的页面是平级的，不会叠在盘子上，所以 Tab 页不能 `navigateTo`，也不能"返回到上一页"——这就是它和普通页跳转的本质区别。传参就是"在盘子上贴张条"，返回结果则是"让下面的盘子把结果递上来"（EventChannel / `navigateBack` 回调）。

**5）异步 = 点外卖。** 下单立刻拿到小票（Promise），`await` 是"等餐到了再动手"，等的过程中照样能刷手机（事件循环不阻塞）。`try/catch` 是"没送到怎么办"：超时、断网、商家拒绝，都要有明确的处理路径；界面上就是**加载中 / 成功 / 空 / 失败**四态。检验：能不能说出"如果请求 8 秒还没回来，用户看到什么"？

## 四、技术选型：7 个维度怎么比

| 维度 | UniApp（Vue3） | ArkTS（ArkUI） | Flutter（Dart） |
|---|---|---|---|
| 语言与学习曲线 | JS 生态，前端零门槛 | TS 超集，有 TS 基础一天上手 | Dart 需新学，但语法与 TS/Java 相近 |
| UI 范式 | 类 HTML 标签 + CSS，前端思维 | 声明式链式属性，贴近 SwiftUI | Widget 组合，样式即代码 |
| 状态管理 | ref/computed + Pinia，轻 | @State/@Link/AppStorage，够用 | setState / Provider / Riverpod / Bloc，选择多 |
| 异步模型 | Promise 单线程 | Promise + TaskPool | Future + Isolate |
| 路由 | pages.json + uni API，页面栈语义清晰 | router.pushUrl/back，Navigation 组件 | Navigator 1.0/2.0，能力最强也最绕 |
| 生态 | 插件市场 + 小程序生态（微信/支付宝都能发） | 华为生态，ohpm 库相对少，系统能力最全 | pub.dev 最大，Material/Cupertino 双设计 |
| 适用场景 | 一套代码多端（H5/小程序/App），中小型业务、快速交付 | 只发鸿蒙、要用系统能力（分布式、元服务）、性能敏感 | 双端高一致性 UI、复杂动效、已有 Dart 团队 |

**决策路径**：目标是"一套代码覆盖 H5 + 微信小程序 + App"→ UniApp；目标是"只发鸿蒙、要接系统能力或元服务"→ ArkTS；目标是"iOS/Android 像素级一致 + 强定制 UI"→ Flutter。三者不是替代关系：真实项目里常见"App 用 Flutter、小程序用 UniApp、鸿蒙版用 ArkTS"。

## 五、互评：先肯定，再给可执行建议

**对 ArkTS 同学**：你用 `@State + ForEach` 把列表和筛选写得很干净，尤其 `keyGenerator` 传了 `stu.id`，避免删项错位，这点很多人会漏。
建议：`filtered()` 每次 build 都会重算，列表上千条时会掉帧。**可执行的做法**是把过滤结果缓存在 `@State displayList`，在 `onChange` 里统一算一次；预期收益是滚动帧率稳定在 60fps。

**对 Flutter 同学**：你用 `ListView.separated` + `ListTile`，列表观感和交互都到位，`mounted` 判断也做对了。
建议：`setState` 里同时改了 `_students` 和 `_loading`，可以合成一次（现在是两行赋值，属于同一批，已没问题），但`_filtered` 在 build 里 `.toList()` 会新建列表。**可执行的做法**是把过滤结果提到 `_keyword` 变更时计算并存字段；预期收益是长列表滚动时减少 GC。
